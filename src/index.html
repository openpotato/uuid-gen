UUID Generator

Generate cryptographically random UUID v4 or time-ordered UUID v7 values.

Standards & references

  • UUID specification: RFC 9562 defines UUIDs, their 128-bit format, versions, variants and standard textual representation; it obsoletes RFC 4122 — RFC 9562.
  • UUID version 4: RFC 9562 §5.4 defines UUIDv4 using random or pseudorandom data, with the required version and variant bits — RFC 9562 §5.4.
  • UUID version 7: RFC 9562 §5.7 defines UUIDv7 with a 48-bit Unix timestamp in milliseconds followed by random data and the required version and variant bits — RFC 9562 §5.7.
  • Text and URN representation: RFC 9562 §4 defines the canonical hex-and-dash text form and shows the urn:uuid: representation; generic URN syntax is defined by RFC 8141 — RFC 9562 §4 and RFC 8141.
  • Cryptographic randomness: Random bytes are obtained with the browser's crypto.getRandomValues(), specified by the W3C Web Cryptography API — Web Cryptography API.
  • Randomness guidance: RFC 4086 / BCP 106 provides general guidance for generating security-sensitive random values and is referenced by RFC 9562 for UUID randomness considerations — RFC 4086.

Runs locally in your browser. No data is transmitted.
